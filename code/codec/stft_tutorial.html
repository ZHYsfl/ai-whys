第 1 节 · 最简单的声音：纯音

麦克风每秒量 16000 次气压，得到一串数字 = 波形。最简单的波形是正弦波，只有两个旋钮：频率（每秒振几圈 → 音高）、幅度（振多猛 → 响度）。拖一拖，听一听：

频率 = 440 Hz   幅度 = 0.8

第 2 节 · 复杂声音 = 纯音相加

两个纯音同时响，气压就是逐点相加。灰 = 两个成分，蓝 = 叠加结果：

成分1 = 440 Hz   成分2 = 880 Hz

任何复杂声音都是一堆纯音的叠加。于是有了逆向问题：给你混合波形，怎么拆出里面的成分？→ 下一节

第 3 节 · 探针：一个频率，一个得分

想知道"信号里有没有频率 f"？拿一个 f 的标准正弦（探针）和信号逐点相乘再全加起来：同步 → 乘积几乎全正 → 得分大；不同步 → 正负抵消 → 得分 ≈ 0。信号固定 500Hz，拖探针频率试：

探针频率 = 500 Hz

↑ 上：蓝 = 信号，红虚线 = 探针。下：乘积（绿正/红负），得分 = 抵消后剩下的总量。

第 5 节 · 频率格与 k：只试 65 个频率就够了

频率有无穷多个，难道每个都试？先动手发现一个规律——拖探针频率，盯三根柱（两路探针都画出来了，第 7 节解释为什么有两路）：

探针频率 = 625 Hz

↓ 乘积 = 信号×探针逐点相乘（绿正/红负）。注意：得分不是某一个点的取值，是这 128 个乘积全部加起来——选一路探针，亲眼看正负面积抵消：  → 正面积 + 负面积 =

规律：窗口里 500Hz 走 4 圈，375/625Hz 走 3/5 圈——圈数差是整数 → 正负面积恰好抵消 → 得分严格为 0；550Hz 走 4.4 圈、差 0.4 圈 → 抵消不完 → 漏分。

所以只要试探"窗口内恰好走整数圈"的频率，它们两两互不干扰：
窗口 = 128 点 = 8 毫秒；走 k 圈 ⇔ 频率 = k ÷ 0.008 = k × 125 Hz。
这些固定下来的频率位置叫频率格，编号 k 就是格子编号（"第 k 格"）。
那为什么 65 格要全部试探？因为你事先不知道信号里有什么频率——换几种信号，看 65 个格子的得分：
当前：纯音 500Hz

第 k = 4 格  → 频率 500 Hz，得分 64.0

读法：峰落在哪格，信号里就有哪个频率；柱子多高，就有多少——得分 = 成分振幅 × 64（探针对准时乘积 = 振幅×sin²，sin² 在窗口里平均恰好 ½，128×½ = 64）。所以双音里振幅 1.0 的 375Hz 得 64 分、振幅 0.8 的 1000Hz 得 51.2 分，一高一矮。纯音只亮 1 格，混合音亮多格，白噪声 65 格全亮：没有一格是多余的。柱子的高度 = 每格的 √(a²+b²)，所以这 65 个数实际是幅度谱；复数频谱则是 65×2 = 130 个数（含相位）。
这 65 个格子是一个"完美俱乐部"：成员之间互相绝对听不见（精确为 0）；但非成员（格外频率，如 550Hz）会被所有格子听见一点，离得越近听得越清——这叫"泄漏"，第 9 节专门处理它。
k 到 64 为止：64×125 = 8000Hz = sr÷2——一个周期至少要 2 个采样点才画得出，这是天花板。（130 个数中 2 个恒为 0，恰好 = 原片段 128 个点的信息量：复数频谱不丢信息，只是换了摆法。）

第 7 节 · 相位陷阱：为什么需要两路探针

此前的探针都是 sin。若信号错开半个节拍（相位不同）呢？拖相位滑块，盯三根柱：

信号相位 φ = 0°

φ 到 90° 时 sin 探针归零——单路探针会把真实存在的成分漏报！cos 探针恰好满格。合并 √(a²+b²) 恒定。所以每个频率格要存两个得分：(a, b)——打包方式就是下节的复数。
可逆性也在这里分家：(a, b) 都在 → 与 128 个采样点等价，可完美复原原波形（白噪声也一样）；只存合并值 √(a²+b²) 就丢了"相位"（成分在窗口内的对时位置），再也回不去——第 6 节那张彩色频谱图就是这么有损的。

第 8 节 · 复数与 eiθ：把两路得分打包

复数 a + bi 就是一对数 (a, b)——平面上的一个点：a 横坐标，b 纵坐标。相乘只有一条规则：i² = −1。

8.1 圆上的点相乘 → 角度相加

(cos30° + i·sin30°) × (cos50° + i·sin50°)
实部 = cos30°·cos50° − sin30°·sin50° = cos(30°+50°) = cos80°   ← 各自套用和角公式
虚部 = sin30°·cos50° + cos30°·sin50° = sin(30°+50°) = sin80°
= (0.1736 + 0.9848i) = (cos80°, sin80°)

8.2 所以起名叫 e 的幂

指数法则 eᵃ × eᵇ = eᵃ⁺ᵇ（乘起来指数相加）与"圆上的点乘起来角度相加"行为一模一样——于是把"角度 θ 的点"命名为 eiθ，旋转就变成了指数加法。欧拉公式 eiθ = cosθ + i·sinθ 不是巧合，是个起得极好的名字。

8.3 单位圆动起来

θ = 30°

↑ 左：单位圆上的点 eiθ（蓝 = cosθ，红 = sinθ）。右：坐标展开成曲线——sin/cos 曲线就是这么来的。

8.4 探针角度 2πkn/N 的由来

① 正弦波的角度写法:  sin(2π·f·t)      ← 一圈 = 2π 弧度；f 圈/秒 × t 秒 = f·t 圈，乘 2π 换成弧度
② 离散化:  第 n 个采样点的时刻 t = n ÷ sr（sr = 采样率 16000）  →  sin(2π·f·n/sr)
③ 格子频率（第 5 节）:  f = k×sr/N
   代入:  2π·(k·sr/N)·n/sr = 2πkn/N   （sr 恰好约掉）
e−i·2πkn/N：n 每加 1，圆上的点多转一小格（k 越大转越快）；横坐标 = cos 探针，纵坐标 = sin 探针。"乘复数探针" = 两路一起乘，得分打包成 (a, b)。|X| = √(a²+b²) = 点到原点的距离（勾股定理）——相位怎么转，距离不变。

横轴 = 探针频率，纵轴 = 得分（默认各自归一化、比形状）。虚线 = 550Hz。

汉宁窗是什么：一条"两端为 0、中间为 1"的砝码（由 cos 改造：w[n] = 0.5×(1−cos(2πn/(N−1)))），每个片段试探前先逐点乘上它，把两端的硬跳变压平——跳变没了，假频率就没了。拖 N 看点数变化：

第 11 节 · 收敛：STFT 总公式

X[m, k] = Σn=0…N−1 x[m·H + n] · w[n] · e−i·2πkn/N

x[m·H + n]第 m 个窗口的第 n 个点（m·H = 窗口起点）→ 10.1
w[n]汉宁窗第 n 个砝码 → 第 9 节
e−i·2πkn/N第 k 格的两路探针打包 → 第 7、8 节
Σ128 个乘积求和 = 得分 → 第 3 节
k = 0…6465 个频率格 → 第 5 节
m = 0…500501 个窗口（16000÷32 = 500 步 + 起点）→ 第 6 节；第 m 列 = 从 m×2 毫秒开始的 8 毫秒片段

|X[m,k]| = √(实²+虚²) = 频谱图第 m 列第 k 行的亮度 = .abs()。

对每个窗口（m）、每个频率格（k）：乘窗 → 乘两路探针 → 求和。torch.stft(...).abs() 至此没有一个符号是陌生的。
